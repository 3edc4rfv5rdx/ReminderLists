# Проверить (Reminders)

> Общее правило теста: **не переводить часы назад** — на этом ломается и авто-удаление, и расписание. Двигать только вперёд.

## Auto-remove after firing (ТЗ 4.2 h)
- [ ] Разовое (One time) с включённым **Auto-remove**, которое **реально сработало** (ушло в неактив) → на следующий календарный день после открытия приложения (холодный старт или возврат на передний план) **исчезает**.
- [ ] Отложенное на тот же день (Postpone/+10) **не** удаляется раньше, чем сработает.
- [ ] Monthly/Yearly с Auto-remove **не** удаляется (продолжает повторяться) — у него живой `next_fire_at`.
- [ ] Напоминание, сохранённое сразу неактивным (никогда не срабатывало), **не** удаляется — авто-удаление только «после срабатывания». (Это и был случай `aaa`.)

## Within-grace catch-up (ТЗ 4.10) — пропущенные «чуть-чуть»
- [ ] Поставить напоминание на «сейчас», выгрузить/переоткрыть приложение в пределах ~10 мин после времени → срабатывает штатным алертом примерно через **минуту**.
- [ ] То же с **Full screen alert** ВКЛ → поднимается полноэкранный экран.
- [ ] То же с Full screen alert ВЫКЛ → обычное heads-up уведомление.
- [ ] Опоздание **больше 10 мин** (телефон/эмулятор был выключен дольше) → только обычное уведомление «пропущено» (не полноэкранный), при нескольких — сводка «N пропущенных».
- [ ] Пропущенный давно **One time** после этого становится **неактивным** (не висит активным вечно) и на след. день авто-удаляется, если у него включён Auto-remove. Monthly/Yearly — переносят дату вперёд.
- [ ] Повторяющееся (Daily/Period) после catch-up продолжает нормально планироваться на следующий раз.

## Notification actions (+10 min / Stop, ТЗ 4.5) — уже работало, регресс
- [+] Обычное уведомление (Full screen alert выкл): **+10 min** переносит на 10 мин, глушит звук и убирает уведомление.
- [+] **Stop** — только глушит звук, уведомление остаётся в шторке.

## Онбординг разрешения на уведомления (ТЗ 4.10)
- [+] На чистой установке при первом запуске — диалог-объяснение (не системный запрос сразу). «Allow» → системный запрос.
- [ ] «Not now» → диалог закрывается, при следующем запуске (пока не выдано) появляется снова.
- [ ] После окончательного отказа диалог меняется на «Open settings» → ведёт в системные настройки уведомлений приложения.

## Interval — новый тип (ТЗ 4.2 f‴ / 4.10)

### Форма (4.2 f‴)
- [ ] Выбор радио `Interval` показывает: базовую **Date** (стартовая), время, рамку **Every** `(–) | NNNN | (+)` и выпадающий список единиц. Чекбоксов Monthly/Yearly repeat, Auto-remove, дней недели и полей Period **нет**.
- [ ] Число вводится вручную (напр. `58`) и подкручивается кнопками; **минус заблокирован на 1** (`N ≥ 1`).
- [ ] Единицы — короткие несклоняемые суффиксы `min / hr / d / wk / mo` (рус. `мин / ч / дн / нед / мес`), «годов» в списке нет.
- [ ] Сохранение требует старт-дату **и** время, `N ≥ 1` и выбранную единицу; иначе — ошибка.

### Планирование (4.10)
- [ ] Ближайшее срабатывание = наименьшее `старт + k·интервал` строго больше `now`; если **старт в будущем** — первое срабатывание = сам старт.
- [ ] **minutes/hours** — абсолютный интервал (реальные секунды): перевод часов на DST/смена пояса шаг не меняют.
- [ ] **days/weeks/months** — по стенным часам: удержать то же локальное время через границу DST.
- [ ] После срабатывания перевзводится следующий слот (цепочка не рвётся).

### Пропущенные и шторка (4.10)
- [ ] Много пропусков (минутный интервал за время сна/выключения) → **одно** уведомление за последний слот, остальные схлопнуты; затем взводится ближайший будущий.
- [ ] Минутный интервал: уведомление **замещает** предыдущее (id = reminders.id, копии не копятся) и само уходит из шторки через ~20 сек (`setTimeoutAfter`). У прочих единиц таймаута нет.

### Кнопки уведомления/алерта (4.5)
- [ ] У Interval есть действие **Stop repeating** — снимает Active, `next_fire_at` → null, алярма отменяется, звук+уведомление гасятся, больше не срабатывает.
- [ ] У **минутного** интервала кнопки **+10 min нет**; у прочих единиц — есть.
- [ ] **Stop** гасит только звук — следующее срабатывание остаётся (как у всех типов).

### Карточка и Today (4.6 / 4.11)
- [ ] Карточка: условие наборной фразой (напр. `Every 3 d` / `Каждые 3 дн`) отдельной строкой **над датой**; последняя строка — ближайшее следующее срабатывание.
- [ ] Папка **Intervals**: сортировка по ближайшему `next_fire_at`.
- [ ] Today-диалог показывает интервалы в единицах **hours и крупнее** (каждый сегодняшний слот отдельной строкой); интервалы в **минутах исключены** полностью.

## Заодно (если будет время)
- [ ] Period числами `5-11` при дате внутри окна → срабатывает по дням окна; `28-3` — окно через границу месяца.
- [ ] Full screen alert: свайп замка вниз глушит звук сразу; Postpone/OK/Done/Continue закрывают и глушат.

# Проверить (Notes, ТЗ 4A) — новый модуль

## Папки и карточки (4A.1 / 4A.3)
- [ ] Вторичный FAB создаёт папку; папки по алфавиту; у непустой — счётчик `(N)` жирным, пустая — без счётчика, обычным.
- [ ] Меню папки «⋯»: Rename / Edit comment / Delete. Удаление папки: «Move contents to root» переносит заметки в корень, «Delete contents inside» удаляет их (и фото файлы).
- [ ] FAB заметки в корне создаёт заметку в корне; в открытой папке — сразу в этой папке.
- [ ] Карточка: слева иконка заметки; строка Title + приоритет (+ иконка фото, + замок); ниже Content, **теги выше даты**, дата.
- [ ] Разделители: только **между** карточками. С комментарием папки внизу — **нет двойного** разделителя.

## Форма (4A.2)
- [ ] Пустой Title → ошибка (красный снек), не сохраняется.
- [ ] Date — свободный текст (напр. «33 февраля»), сохраняется как есть; пикатель подставляет `YYYY-MM-DD`.
- [ ] Фото (до 10), теги (общий справочник, `#`-пикер), приоритет — сохраняются и подтягиваются при повторном открытии.
- [ ] Полей срабатывания (Active/повтор/времена/звук) в форме заметки **нет**.

## Тап по карточке / viewer / фото (4A.3)
- [ ] **Открытая** заметка с фото: тап → сразу фото-viewer (свайп, добавить/удалить).
- [ ] Открытая заметка **без** фото: тап ничего не открывает (тело и так на карточке).
- [ ] **Закрытая (PIN)** заметка: тап → запрос PIN → read-only viewer (Title/приоритет/Content/теги/дата + кнопка **Photos (N)** → фото-viewer). Кнопки цветные: OK/Edit/Photos.
- [ ] Edit из viewer открывает редактор без повторного PIN.

## PIN (4A.4)
- [ ] Protect через «⋯» (свой PIN или Default из настроек). У защищённой — иконка замка, тело/дата/теги/иконка фото **скрыты** на карточке.
- [ ] PIN требуется на: открыть (тап), Edit, свайпы, В папку, Share, снять защиту/сменить, удалить.
- [ ] Фото защищённой заметки **не** открываются мимо PIN (только через viewer после PIN).

## Действия карточки (4A.3)
- [ ] Свайп вправо → Edit (защищённая — через PIN), свайп влево → Delete (с подтверждением).
- [ ] «В папку» перемещает; Share шлёт Title + Content.

## Фильтры и сортировка (4A.5)
- [ ] Свой независимый фильтр вкладки Notes; индикатор All/T/F/TF в топ-баре; нажатие на активный индикатор открывает соответствующий фильтр; «Clear all filters» сбрасывает.
- [ ] Filters для Notes: **Date from/to, Tags, Priority** — переключателя «Active only» **нет**.
- [ ] Tag Filter: облако тегов считает **заметки** (счётчик в контексте вкладки Notes).
- [ ] При активном фильтре **пустые папки скрыты**; счётчик папки = число совпавших заметок.
- [ ] Фильтр по дате отсекает только заметки с распарсенной `YYYY-MM-DD`; с пустой/нераспарсенной датой — не отсекаются.
- [ ] Сортировка: распарсенные даты старые сверху, остальные — в конец по Title.
- [ ] Фильтр, не дающий совпадений, предупреждает синим снеком и остаётся.

## Общий справочник тегов
- [ ] Тег, оставшийся без заметок И без напоминаний, удаляется из справочника (после смены тегов/удаления заметки).
